# v0.6.0 - Data Integrity and Repository Cleanup

This release candidate improves the reliability and maintainability of the local time-tracking CLI.

- Safer atomic Excel writes, validated before replacement, with one previous version per day.
- Recoverable draft workflow and clear separation between saved raw records and failed output rebuilding.
- Explicit source-data read failures and safer category configuration creation.
- Fully synthetic sample dataset and pytest regression suite.
- Basic GitHub Actions CI, a simple implementation package, and a preserved `python main.py` launcher.
- Repository cleanup, English engineering documentation, and MIT licensing.

The application UI remains Chinese. User records and derived output remain local and excluded from Git. No binaries, web deployment, or PyPI package are included.
